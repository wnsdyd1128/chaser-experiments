# Memory-gap SIM 실험 기록 위치

이 시나리오의 입력·측정 결과·해석은 Git에서 제외한
`.cache/periodic-memory-gap-v1/reports/`에 보존한다.

- `README.md`: 실험 구성과 측정 결과
- `EXPERIMENT-AUDIT.md`: 비교 조건과 해석 점검
- `SIM-FOLLOWUP.md`: 후속 대조와 같은 ELF 진단

실행 코드와 raw도 `.cache/periodic-memory-gap-v1/` 및
`.cache/configs/periodic-memory-gap/`에 있다.
